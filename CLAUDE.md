# Правила проекта mostik

## Производительность
- Нужна максимальная производительность при минимальном расходе памяти.

## Отчёт о результатах
- После изменений, влияющих на скорость, размер или память, всегда показывать таблицу сравнения: MongoDB / было / стало — по каждой затронутой метрике (время операций, размер на диске, память).
